# BLOODSKY

**Android HMI и FBD — предварительная версия инструментов сборки и тестирования.**

BLOODSKY — рабочий проект по адаптации Android-приложения для локальных HMI-проектов, FBD и подключения контроллеров. Название продукта и пользовательское оформление — **BLOODSKY**. Техническое происхождение используемой кодовой базы и ресурсов указано отдельно в [NOTICE.md](NOTICE.md); проект не заявляет исключительное авторство исходного приложения.

## Проверено на Android 11

- Установка экспериментальной QA-сборки и запуск без интернета; главное меню на русском языке `ru-RU`.
- Создание локального проекта, сохранение, поиск в списке и повторное открытие в редакторе.
- Панель HMI: переключатели, кнопки, задатчики, текст, цифровые индикаторы.
- Панель FBD: переменные, RS-триггеры, таймеры и другие оригинальные категории.
- Геометрия и пиксели шести основных кнопок меню идентичны исходной сборке в условиях одного эмулятора (не означает совпадение всех экранов).

## Статус

**Предварительная техническая версия. Не является стабильным релизом Android-приложения.**

Недостаточно проверены: сохранение проектов с размещёнными виджетами, выполнение схем FBD, импорт/экспорт, все остаточные облачные вызовы, реальные Wi-Fi/USB/Bluetooth/Modbus-подключения, совместимость с новыми версиями Android, права на распространение базовых ресурсов и постоянная релизная подпись.

Последние подтверждённые проверки: [Android QA](https://github.com/skynet909084-boop/BLOODSKY/actions/runs/40553232969), [визуальная сверка](https://github.com/skynet909084-boop/BLOODSKY/actions/runs/40553233451), [панель HMI](https://github.com/skynet909084-boop/BLOODSKY/actions/runs/40555577752), [панель FBD](https://github.com/skynet909084-boop/BLOODSKY/actions/runs/40556295416).

## Что входит в репозиторий

Здесь находятся инструменты патча, проверки целостности, сценарии Android-эмулятора, журнал изменений и документация. **Исходный сторонний APK, его декомпилированный архив, приватные ключи и пароли сюда не загружаются.** Изменения воспроизводятся только при наличии исходного файла, который пользователь вправе применять и модифицировать.

Для локального тестирования см. [инструкцию сборки](docs/BUILD.md), [матрицу приёмки](docs/ACCEPTANCE.md) и [аудит внешних зависимостей](docs/CLOUD_RISK_AUDIT.md).

## Сборка и публикация

Проверенные тестовые APK были подписаны временным ключом, различающимся между запусками. Они не предназначены для стабильных обновлений. После перевода старого репозитория в приватный архив для получения входного APK в CI требуется отдельный read-only GitHub Actions Secret, описанный в [docs/BUILD.md](docs/BUILD.md).

**Публичный предварительный выпуск распространяет исходные инструменты и документацию, но не модифицированный сторонний APK.** Публикация установочного пакета требует подтверждённых прав на распространение использованных ресурсов, полной проверки функций и постоянной защищённой подписи.
