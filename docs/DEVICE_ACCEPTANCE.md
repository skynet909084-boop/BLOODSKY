# BLOODSKY — приёмка на физических Android-устройствах

## Статус

На 27 октября 2026 года **нет результатов испытаний именно Beta 2 на реальном устройстве**. Предыдущие успешные Android 11 тесты проходили на эмуляторе и относятся к предыдущему APK.

## Автоматическая проверка

Нужен телефон/планшет с разрешённой отладкой ADB и установленными Android platform-tools. Предварительно сохраните проекты: у BLOODSKY новый сертификат и прежний Android package. **Не удаляйте старую установку без резервной копии.**

```bash
bash tests/physical_device_smoke.sh /path/to/BLOODSKY-1.0.7-beta2-branded-project-key.apk
```

Скрипт сверяет SHA-256, отвергает эмуляторы, устанавливает APK без удаления предыдущих данных, проверяет запуск/процесс, сохраняет скриншот, UI и ошибки AndroidRuntime в `out/physical-device-acceptance/`. Не публикуйте персональные данные и полные системные логи в публичном GitHub.

## Ручная матрица

- [ ] Модель устройства, Android API, дата, контрольная сумма установленного APK подтверждены.
- [ ] BLOODSKY открывается, русское меню и новые иконки выглядят корректно.
- [ ] Создание, изменение виджетов, сохранение, перезапуск, повторное открытие проекта с сохранёнными настройками.
- [ ] FBD: переменная, RS-триггер, таймер; связи, вычисление, сохранение и повторный запуск.
- [ ] Импорт/экспорт проекта из локального хранилища и обратное открытие.
- [ ] Wi-Fi/Modbus TCP: чтение и запись на физическом контроллере; обрыв и восстановление связи.
- [ ] Bluetooth: реальный адаптер, сопряжение и обмен.
- [ ] USB: реальное устройство, разрешение, обмен и отключение.
- [ ] Полная работа без Интернета, сетевой аудит первого запуска и проекта: нет обращений к старым облачным сервисам.
- [ ] Проверка установки обновления тем же постоянным сертификатом с сохранением проектов.

**Не отмечать пункты без фактического испытания.** Для заявления «проверено на реальных устройствах» сохранить обезличенные отчёты, скриншоты и результаты. Даже успешный физический запуск без подключения контроллера не подтверждает Modbus/USB/Bluetooth.
