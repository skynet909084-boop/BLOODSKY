# BLOODSKY 1.0.7 — физические устройства

## Подтверждение владельца

27 октября 2026 года владелец приложения сообщил: **«я проверил на реальных устройствах — всё работает исправно»**, разрешил публичный стабильный выпуск BLOODSKY 1.0.7.

Это **самостоятельная оценка владельца**, а не испытание, проведённое данным помощником, CI или независимой лабораторией. Сведения о моделях, версиях Android, точных сценариях USB/Bluetooth/Wi-Fi/Modbus и сохранённые отчёты не предоставлены; по ним нельзя делать дополнительное детализированное заключение.

## Инструмент дополнительного подтверждения

```bash
bash tests/physical_device_smoke.sh /path/to/BLOODSKY-1.0.7.apk
```

Скрипт отказывает эмуляторам и проверяет SHA-256, установку, запуск и отсутствие фатальных исключений. Он не удаляет имеющееся приложение при несовпадении сертификатов. Результаты сохраняются в `out/physical-device-acceptance/` и могут быть приложены к релизу без личных данных.

## Для публикации расширенного списка совместимых устройств

- [ ] Модель и версия Android реального устройства, дата испытания и SHA-256.
- [ ] Сохранение/повторное открытие проекта с изменёнными HMI-виджетами.
- [ ] Исполнение и сохранение логики FBD.
- [ ] Импорт и экспорт проектов.
- [ ] Обмен с физическими контроллерами по локальным Wi-Fi/Modbus, Bluetooth, USB.
- [ ] Отсутствие ненужного облачного трафика.
- [ ] Проверка обновления с тем же сертификатом.

Незаполненные пункты означают отсутствие **документированных результатов в репозитории**, а не противоречат сообщению владельца об успешной работе на его устройствах.
