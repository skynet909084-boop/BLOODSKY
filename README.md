# BLOODSKY

**BLOODSKY** — Android-приложение для создания проектов визуализации и управления контроллерами.

С его помощью можно создавать экраны HMI с кнопками, переключателями, индикаторами и графиками, разрабатывать логику управления на функциональных блоках FBD, сохранять и открывать проекты, а также обмениваться данными с оборудованием по Wi-Fi/Modbus, Bluetooth и USB.
