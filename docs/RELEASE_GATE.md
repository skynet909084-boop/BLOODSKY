# BLOODSKY — критерии публичного APK

## На текущем этапе

Допустимо: выпуск исходных инструментов, тестов, отчётов и предварительного тега без сторонних бинарных файлов.

Недопустимо объявлять текущую сборку полноценно проверенным стабильным APK или приписывать себе оригинальный код и ресурсы. Пользовательское оформление может называться **BLOODSKY**, но происхождение кодовой базы необходимо указывать в техническом уведомлении.

## Что требуется для APK-выпуска

- [ ] Документировано право публично распространять использованные сторонние ресурсы и производный APK.
- [ ] Аудит отсутствия обращений к прежним облачным сервисам и безопасная обработка проектов с прежним типом подключения.
- [ ] Проверено сохранение, повторное открытие и импорт/экспорт проектов с реальными HMI-виджетами.
- [ ] Проверены добавление, параметры, связи, сохранение и выполнение FBD.
- [ ] Проверены реальные локальные Wi-Fi/USB/Bluetooth/Modbus-соединения.
- [ ] Проверены Android 11 и актуальная версия Android на устройстве.
- [ ] Подготовлен постоянный защищённый ключ релизной подписи, отдельный от QA; пройдена проверка подписи, версий и возможности обновления.
- [ ] Созданы release APK и SHA-256; release notes разграничивают подтверждённые и непроверенные функции.
