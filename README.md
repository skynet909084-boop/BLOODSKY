# BLOODSKY

**BLOODSKY 1.0.7 — Android HMI / FBD**

BLOODSKY предназначен для локальных проектов визуализации и работы с контроллерами. Пользовательский интерфейс и оформление выпускаются под брендом BLOODSKY.

## Версия 1.0.7

Владелец проекта **27 октября 2026 года подтвердил, что лично испытал BLOODSKY на реальных Android-устройствах и приложение работает исправно**. Это подтверждение владельца, а не независимый протокол тестовой лаборатории. Модели устройств, версии Android и журналы подключения контроллеров отдельно не представлены.

**Контрольная сумма официального кандидата 1.0.7:**

```text
7e2a823afaeb1c8255709fa4afa88963963e00fc61f06fe063c880ac725ffc71  BLOODSKY-1.0.7.apk
```

APK подписан постоянным сертификатом проекта BLOODSKY (Android v1/v2/v3). Файл с названием `BLOODSKY-1.0.7.apk` побайтно идентичен подписанной и перебрендированной сборке Beta 2; изменено **только имя файла**, не байты и не подпись. Перед установкой сохраните проекты: обновление поверх приложений, подписанных другим сертификатом, может потребовать переустановки.

**GitHub Release:** [BLOODSKY 1.0.7](https://github.com/skynet909084-boop/BLOODSKY/releases/tag/v1.0.7). При публикации страницы GitHub бинарный файл нужно прикрепить отдельно; до проверки вложения не считайте его доступным для скачивания прямо из GitHub Releases. Версию и SHA-256 сверяйте до установки.

## Проверки

**Реальные устройства:** испытания владельца проекта — подтверждены им в переписке 27 октября 2026 года. Независимый отчёт с перечнем устройств, версий Android, типов подключений и логами пока не опубликован.

**Автоматизированные тесты предыдущей сборки:** Android 11 на эмуляторе, запуск без интернета, русское меню, создание/сохранение/повторное открытие проекта; панели HMI и FBD; визуальное совпадение шести главных кнопок.
